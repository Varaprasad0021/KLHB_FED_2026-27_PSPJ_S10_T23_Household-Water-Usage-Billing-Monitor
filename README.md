## ABSTRACT
The Household Water-Usage & Billing Monitor is a Java-based application designed to monitor household water consumption and calculate water bills based on meter readings. The project also helps identify excessive water usage and possible leaks.

## CURRENT PROGRESS
- Week 1: Console readings and basic bill display - Completed
- Week 2: Occupant count and leak status - Completed

## SETUP
1. Install Java JDK.
2. Open the project in a Java IDE such as VS Code.
3. Open the project folder.
4. Open the src folder to access the Java files.

## EXECUTION
1. Open Main.java.
2. Run the program.
3. Select an option from the menu.
4. Enter the household and meter details.
5. View the water consumption and bill.
6. Enter the number of occupants and leak status when prompted.
