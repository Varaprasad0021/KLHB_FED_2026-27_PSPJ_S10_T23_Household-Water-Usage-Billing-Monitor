ABSTRACT :
The Household Water-Usage & Billing Monitor is a Java-based console application designed to monitor water consumption in residential households. The system records meter readings, calculates water usage, and generates bills based on different usage levels. It also helps identify excessive water consumption and possible leaks. The project aims to promote efficient water usage, reduce wastage, and help households monitor their water consumption and billing.

SETUP :
Install Java JDK and open the project in a Java IDE such as VS Code.

Execution Instructions :
Open the project in a Java IDE.
Open Main.java.Run the program.
Select an option from the menu.
Enter the required household and meter reading details.
View the water usage, bill, leak detection, and report results.
